# Repository instructions

Run the narrowest relevant test before running the full suite.

Before editing:

1. State the goal and its acceptance criteria.
2. Name the files you expect to be relevant.
3. For changes spanning more than one module, propose a plan first.

Avoid reading `archive/` and large files under `fixtures/` unless the task
explicitly requires them.

Do not modify unrelated files and do not weaken existing tests.
